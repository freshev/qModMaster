1. Описание
QModMaster — это бесплатная реализация приложения ModBus master на основе Qt. Графический пользовательский интерфейс обеспечивает простую связь с подчиненными устройствами ModBus RTU и TCP. QModMaster также включает монитор шины для анализа всего трафика на шине.

2. Программное обеспечение
QModMaster основан на QModBus <http://sourceforge.net/projects/qmodbus/> и libmodbus 3.1.0-1 <http://www.libmodbus.org/>. Поддерживает как Windows, так и Linux.
https://sourceforge.net/u/elbar/profile/
